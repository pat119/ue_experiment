# ue_experiment
Runs an experiment on a target object to test a computer vision model
Comments in adv_sam_camera_texture_server.py indicate where to change experimental parameters (camera viewpoint, target object name, target object position, etc.)
You will need to add textures to your UE project file, and make a texture_paths.json file.
Ensure you have torch, unrealcv, and required modules in your environment.
